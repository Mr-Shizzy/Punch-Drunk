Not included
------------

Microsoft's Visual C++ runtime and the .NET SDK are Microsoft's, and their licences don't allow anyone
else to hand them out, so this download contains neither. If Windows lacks the Visual C++ runtime the
game's graphics libraries need, the launcher downloads Microsoft's own installer from Microsoft
(https://aka.ms/vc14/vc_redist.x64.exe), checks Microsoft's signature on it and runs it with Windows'
permission prompt. The translator below carries the .NET runtime it needs inside it (MIT).

The build kit (resources\buildkit)
----------------------------------

Everything the first build needs, so setup works without internet. Each file is the publisher's own
download, unmodified and checked against a pinned checksum (resources\buildkit\manifest.json lists them).
The launcher unpacks what it needs into the data folder during a build and removes it afterwards.
Each archive carries its own licence text inside it, except the ones marked [licenses\], whose texts are
in resources\buildkit\licenses.
